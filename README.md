# مُعين (Mueen) - تطبيق القرآن الكريم للمكفوفين 🕌

**مُعين** هو تطبيق أندرويد مصمم خصيصاً لتسهيل استماع وتصفح القرآن الكريم للمكفوفين وضعاف البصر، مع دعم كامل للأوامر الصوتية وتوافق تام مع قارئ الشاشة **TalkBack**.

## الإنجازات والتحديثات الأخيرة 🚀

تم مؤخراً إنجاز مجموعة من التحسينات الجذرية لضمان أفضل تجربة استخدام (Accessibility UX):

1. **التوافق التام مع TalkBack:**
   - منع التداخل الصوتي بين المساعد الداخلي للتطبيق (TTS) و TalkBack.
   - إضافة `contentDescription` دقيق باللغة العربية لكافة الأزرار والأيقونات ليتولى TalkBack قراءتها بالصوت المفضل للمستخدم.
2. **تحسين الأوامر الصوتية (Voice Commands):**
   - إصلاح مشكلة حجب خدمة `RecognitionService` في نظام أندرويد 11 وما فوق (API 30+) عن طريق إضافة تصريحات `<queries>` في ملف `AndroidManifest.xml`.
   - بناء نظام **تطبيع النصوص العربية (Arabic Normalization)** لمعالجة اختلافات محرك تحويل الصوت إلى نص (مثل التمييز التلقائي بين الهاء والتاء المربوطة، وتوحيد الهمزات).
   - منع تعارض الـ Audio Focus بين الميكروفون ونطق الهاتف لتجنب الإغلاق المفاجئ لخدمة الاستماع.
3. **دعم اللغة العربية وواجهة المستخدم (RTL):**
   - إصلاح اتجاه الواجهة بالكامل من اليمين إلى اليسار وتطبيق خطوط عربية واضحة ومقروءة.
   - تحسين تناسق الألوان والتباين (Contrast) لدعم ضعاف البصر (تدرجات الأزرق الداكن والذهبي).
4. **تطوير البنية التحتية والملاحة:**
   - إدارة التحكم في تشغيل السور والانتقال بين الآيات والمقاطع.
   - توفير نافذة متخصصة لاختيار القراء، وفهرس السور، ودليل الأوامر الصوتية.

---

*هذا المشروع يتم تطويره وصيانته بدعم من مساعدي الذكاء الاصطناعي (Autovem) مع التركيز الصارم على معايير الجودة والنظافة البرمجية.*
